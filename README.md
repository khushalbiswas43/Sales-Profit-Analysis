# 📊 Sales & Profit Analysis Dashboard

## Project Overview

This project is a Sales and Profit Analysis Dashboard created using Microsoft Power BI.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 📌 Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Sales by Region
- Sales by Category
- Monthly Sales
- Profit by Category
- Top Performing Products

## 📂 Files Included

- `Sales_Profit_Analysis.pbix` — Power BI project file
- `sales_data.xlsx` — Dataset
- `dashboard.png` — Dashboard preview

## 🎯 Objective

The objective of this project is to analyze sales performance and identify important business insights using Power BI.
